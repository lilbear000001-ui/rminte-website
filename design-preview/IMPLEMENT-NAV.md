## 2. 要做的事（只有这些）

**材质统一**：导航岛、语言按钮、菜单按钮、弹层使用同一材质（石墨 n-3、1px 描边），不用真玻璃、不加新颜色。

**光段（倒角边光）只加在两处**：导航岛、联系弹窗大框。语言按钮、手机菜单按钮、页脚「联系我们」按钮、语言下拉菜单都**不加**。复用现有 `[data-bevel]` 与 `motion.js` 的 `--bx`，不新增 JS。参数：导航岛 `--bi:32px`，联系大框 `--bi:24px; --ba:.6`；其余沿用默认（`--bw:30%`、`--ba:.5`、惯性 0.14；触屏与减少动效时固定在中间）。

1. **导航岛**：`--glass-bg` 不透明度 85% → 92%（`brand.css` 令牌内改）；描边 `line-1` → `line-2`，与语言、菜单按钮一致。首页章节高亮改为白 10% 底 + 1px `line-2` 环；子页的「当前页」银白胶囊不变。
2. **语言切换**：按钮高度不变（桌面 42px，≤1120px 44px）；展开时箭头旋转 180°（240ms）。下拉面板：n-3、1px `line-3` 描边、8px 圆角，**去掉投影**；每项 40px，选中项文字提亮并在右侧显示蓝宝石（`--sapphire-300`）对勾（SVG，24 坐标、1.6 线宽、圆角端点，显示尺寸 16px），不再用整块灰底；悬停 `line-1` 底；进场 240ms（透明度 + 上移 4px + 缩放 .98，origin 右上）。保留键盘、Esc、点击外部关闭与现有 aria。
3. **联系弹窗**：标题 28px；面板 n-3、1px `line-3`、8px 圆角、顶边光段；打开时页面压暗（`rgba(0,0,0,.55)`，无 backdrop-filter，360ms）、背景 `inert`、弹层加 `aria-modal="true"`；焦点落在 44px 圆形关闭按钮，Esc/点击压暗层/关闭按钮关闭并把焦点还给触发按钮。入口行：上缘 1px `line-2` 细线，标签 13px、邮箱 17px；悬停/焦点时蓝宝石下划线 480ms（reveal 缓动）从左画出，箭头向右上位移 2px（240ms）。文案、顺序、链接、四个入口都不变，**不要新增 kicker 或其他文字**。
4. **手机**：顶栏、语言菜单沿用以上材质；联系弹窗两侧留 16px、贴底；全屏菜单条目 32px，每行上下 1px `line-2` 细线，左侧 Geist Mono 序号 01–06（纯装饰，`aria-hidden`，当前页序号用蓝宝石色），顶部 Logo 与 44px 圆形关闭按钮。
