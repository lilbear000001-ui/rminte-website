## 色彩

冷石墨中性色阶，色相约 220°，色度极低：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| n-0 | `#000000` | 产品页与图册画布 |
| n-1 | `#07080A` | |
| n-2 | `#0D0F12` | 支持页（下载／指南）背景；模型卡片 |
| n-3 | `#14171B` | 支持页面板 |
| n-4 | `#1C2026` | 悬停 |
| n-5 | `#2A3037` | |
| n-6 | `#585F69` | 仅装饰 |
| n-7 | `#858C95` | 说明／元信息 |
| n-8 | `#B6BCC4` | 次级文字 |
| n-9 | `#F2F4F6` | 主文字 |

文字对比度（在 `#000` 上）：text-1 19.0:1、text-2 11.0:1、text-3 6.2:1（通过 AA）、text-4 3.3:1（不得承载信息）。text-2 在 `#0D0F12` 上为 10.0:1，在原 `#141618` 上为 9.5:1。

线条：line-1 `rgba(255,255,255,.08)`（列表、表格），line-2 `.14`（卡片、按钮），line-3 `.24`（悬停、章节线）。

信号色：sapphire-300 `#A8B8F0`（文字／线，在黑上 10.8:1）、sapphire-500 `#6E86E0`（图表，6.1:1）、sapphire-wash 12% 填充、thermal-warm `#E58B5A`（只用于温度数据）、状态琥珀 `#E5B15A`（root 高权限小点，功能语义，不单靠颜色表达）。

用途白名单：键盘焦点环、当前选中指示、滚动进度、规格数值的单位、链接悬停下划线、章节遥测细线。禁止：渐变（冷暖线除外）、发光、大面积底色、按钮底色。图册页不使用蓝宝石色，焦点环保持银白。

## 字体与字阶

Geist + Noto Sans SC 为界面字体；Geist Mono 用于数字（D2）；Geist Pixel Circle 用于 28px 及以上的大数字与单位（D7）；Quantify RM 只用于品牌字标。

| 层级 | 尺寸 | 备注 |
| --- | --- | --- |
| display | clamp(64px, 11.7vw, 168px) | Quantify RM，行高 .95 |
| h1 | clamp(40px, 4.4vw, 64px) | 500，字距 -0.04em，行高 1.05 |
| chapter | clamp(36px, 3.89vw, 56px) | 首页章节标题（画板 05），500，字距 -0.04em，行高 1.1；令牌 `--chapter-title`，整机协同桌面例外 clamp(32px, 2.8vw, 43px) |

| h3 | 24–28px | 500，行高 1.25 |
| lead | 18–20px | 400，行高 1.7，text-2 |
| body | 16px | 400，行高 1.8（中）／1.7（拉丁） |
| caption | 13px | 行高 1.6，text-3 |

指南正文沿用现行 DESIGN.md 的 h2／h3／h4 层级；行高由 1.9 收到 1.85。六语言各自检查换行与字形，日韩使用对应字形回退。

## 间距、圆角

间距 4pt 基准：4、8、12、16、24、32、48、64、96、128、192。圆角：4 控件、8 小面板、16 大卡片与影像（新增）、999 胶囊。

## 动效

时长：120（按压）／240（悬停）／480（面板）／800（入场）／1200ms（数字计数）。缓动：settle `.32,.72,0,1`（已有，不变）、reveal `.16,1,.3,1`（新增，文字行遮罩上移）、exit `.4,0,1,1`（离场，时长取 60%）。编排：标题逐行 → 正文 → 行动，错峰 70ms，总长不超过 1.2s。`prefers-reduced-motion`：关闭位移与计数，仅保留 120ms 透明度变化，内容始终完整可见。

## 组件

- 按钮：48px 胶囊；主行动银白底深色字；悬停提亮到 `#FFFFFF`、位移 -1px、240ms；按压缩放 .98、120ms；焦点环 2px 蓝宝石 + 2px 黑隔离（对比度 ≥ 3:1）。
- 卡片：16px 圆角、n-2 底、1px 内描边、顶边 1px 高光线（两端渐隐，模拟机身倒角）；无阴影、无发光。
- 导航：六项，顺序不变：图册、模型、产品、架构、指南、下载；当前页银白底，不用彩色。
- 语言：六语言下拉，显示当前语言，不用国旗。
- 链接：悬停时下划线从左向右展开，480ms，reveal 缓动。
- 图标：SVG、24 坐标系、1.6 线宽、圆角端点；不用字体字符代替操作图标。
