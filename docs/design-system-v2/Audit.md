# 现状诊断

依据：仓库 `DESIGN.md`／`AGENTS.md`、`brand.css`、`styles.css`（约 84KB、180 处 `@media`）、线上 rminte.com 抽查。抽查只用窄屏视口浏览，桌面像素级复核未做。下列数字来自文件测量，尚未做实机网络测量。

| # | 问题 | 证据 | 对策 | 优先级 |
| --- | --- | --- | --- | --- |
| 01 | 颜色令牌碎片化 | `styles.css` 约 40 种白／黑透明度（.035–.94）；写死的 `#9a9da1`、`#b9bcbe` | 十级中性色阶与三级线条，旧值一一映射 | P0 |
| 02 | 首屏被「语言切换」卡住，媒体过重 | `html.i18n-loading body{visibility:hidden}` 直到 333KB `translations.js` 载入；`hero-bg.mp4` 19.6MB、热管理视频 10.3MB、`img4.png` 7.5MB、多张 2–3MB PNG | 首屏文案直出 HTML、其余语言按需加载；视频只优化编码并海报先行；首页 PNG 转 WebP | P0 |
| 03 | 字阶与行高无体系 | 仅标题有流体字号；正文行高 1.9 偏松；规格数字写成整段灰字 | 九级字阶；数字用等宽；中文行高收到 1.8 | P0 |
| 04 | 硬件模块卡片层级弱 | 卡片大量空白、规格挤在底部 12px 灰字、两张卡内容长度不同导致底部不齐 | 卡片拆成标题／一句话／规格网格三层；顶边加倒角高光线 | P1 |
| 05 | 缺少标志性点缀 | 全站纯单色，产品自身的冰蓝宝石与热管理冷暖光没有被利用 | 蓝宝石信号色（D1），限定用途 | P1 |
| 06 | 首屏层次平 | 指标行小字置于视频底部；标题与副标题字号接近；缺入场编排 | RM-01 字标放大为视觉锚（D3）；指标点阵数字化 | P1 |
| 07 | 动效只有一条缓动曲线 | 仅 `--motion` 一个令牌；无时长阶梯、无入场编排、悬停与焦点无统一反馈 | 五档时长、三条缓动、70ms 错峰 | P1 |
| 08 | 全屏点阵叠层 | `body::after` 在整页叠 2.2% 不透明度 `screen` 混合的点阵与横线，肉眼几乎不可见却占一个全屏合成层 | 删除，或换成 3–4% 静态颗粒（D4 已确认，只限首页与模型页） | P2 |
