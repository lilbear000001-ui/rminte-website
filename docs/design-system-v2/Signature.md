# 标志性设计语言

目标：让官网「只属于 RM-01」。五个手法都取自产品本身，不借用行业模板。画板：`boards/Signature.png`。方向已确认，实现细节在实施阶段按下列边界做。

| # | 手法 | 来源 | 用在哪 | 边界 |
| --- | --- | --- | --- | --- |
| 01 | 棱镜 Prism | 蓝宝石窗口的三角形 | 章节标记（取代短横线，12px 空心倒三角，`#A8B8F0` 描边，2px）；影像悬停时光标变棱镜加「查看」；页面切换用三角形光圈展开（480ms、reveal 缓动） | 只描边与 12% 填充，不发光；每屏最多出现一次大尺寸 |
| 02 | LED 点阵数字 | RM-01 前面板的圆点 LED 矩阵 | 首屏指标（140W、64、7×24、30B–200B）、规格大数字、图册计数「09 / 11」、Dense／MoE 示意、指南角色图标；数字进入视口时逐位点亮，1.2s | Geist Pixel Circle（D7）；只用于数字与单位，不用于标题与正文；小于 28px 改回 Geist Mono；减少动效时直接显示 |
| 03 | 倒角边光 | 阳极氧化铝机身倒角上的一线反光 | 卡片、按钮、搜索框：指针经过时，顶边的高光段跟随指针横向移动 | 只有 1px 线，无模糊、无阴影；触屏与减少动效时固定在中间 |
| 04 | 遥测栏 | 设备「报告自己状态」的语气 | 首页与长页面的左侧细栏：当前章节名称、滚动进度百分比 | 只显示名称，不带序号；≥1280px 才显示；手机隐藏；不遮挡内容 |
| 05 | 冷暖线 | 散热视频里真实的气流颜色 | 热管理章节的温度示意曲线、模型评测发布后的曲线、功耗条 | 全站唯一允许的渐变：`#E58B5A` → `#6E86E0`，只出现在数据线与细线上，宽度 ≤ 2px；不做背景渐变、不做按钮渐变；示意曲线需标注「示意」，不得当成实测数据 |

## 与现有规范的关系

- 不改变首页视频、滚动分解、蓝宝石点亮、工艺切换及其参数。
- 章节标签仍不带序号；遥测栏只显示名称。
- 棱镜符号与蓝宝石色只作细线与描边，不引入蓝紫渐变或光晕。
- 新增字体 Geist Pixel 需加入网站字体资源（OFL，保留许可文件）。

## 已知未验证

逐位点亮、指针边光、棱镜光圈转场目前只有静态稿，没有动效原型；性能与减少动效行为需实施后实测。
