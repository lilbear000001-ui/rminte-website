# 媒体策略（D5）

原则：图册照片是禁区；视频分辨率不变；每一版优化都要与原文件并排比对，观感不如原版则放弃。

| 对象 | 规则 |
| --- | --- |
| 首页视频 | 分辨率不变（降分辨率试过，效果很差）。只在编码层面做功课：同分辨率、同观感下降低码率、关键帧间隔、`faststart`、海报先行、非首屏视频进入视口才加载。只限首页。状态：首屏视频的海报已加（`hero-bg-poster.jpg`，视频第一帧，1920×1080 JPEG，86KB，2026-10-05）；非首屏视频进入视口才加载，用户 2026-10-05 决定先不做 |
| 首页 PNG | 转 WebP，只限首页使用的 PNG（img3／img4、散热叶片与模块图、握卡海报等）。先确认每张的实际引用位置，不动被其他页面引用的文件 |
| 图册 11 张照片 | 保持原文件、原分辨率、原 HDR 信息。任何滤镜、叠层、压缩、尺寸变化都不应用于照片；颗粒不覆盖其上。可做的只有不改文件的加载优化（预取相邻一张、解码提示、缓存头），且需实测后才下结论 |
| 其他页面 | 模型、下载、指南的图片与视频本轮不动；如要动，先单独列出请用户确认 |

测得的体积（文件大小，非实机加载表现）：`hero-bg.mp4` 19.6MB、热管理循环视频 10.3MB、`img4.png` 7.5MB、其余多张 2–3MB PNG。实际加载行为（谁先加载、是否被缓存）尚未测量。
