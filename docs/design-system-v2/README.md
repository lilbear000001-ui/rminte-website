# 设计系统 v2：目标、决定与差异

## 目标

官网保持「黑色画布、银白克制、真实影像叙事」的既定方向，把它从「能看」做到 Awwwards、Webby Awards、FWA 获奖水准。重点不是换风格，而是补齐四层：令牌体系、字阶与数字表达、动效编排、源自产品本身的细节语言。

## 现状一句话

证据优先（摄影与影像承担表达）、克制的单色、滚动即叙事。缺的是体系：全站约 40 种散落的白／黑透明度、写死的灰、单一缓动曲线、没有任何点缀色、硬件卡片留白失衡。详见 [Audit.md](Audit.md)。

## 始终不变的约束（来自 DESIGN.md／AGENTS.md）

首页与图册纯黑；白色矢量 Logo，不描边不发光；Geist／Noto Sans SC 为界面字体，Quantify RM 只用于品牌字标；胶囊文字按钮（999px），信息面板 8px，表格与文件标识 4px；图标 SVG、24 坐标系、1.6 线宽、圆角端点；章节标签不带序号；下载与指南入口不显示分组数量或卡片序号；保留首页视频自动播放、滚动分解、蓝宝石点亮（参数不动）、工艺切换；图册 `object-fit: contain`、11 张、不加分隔线与进度条；尊重 `prefers-reduced-motion`；六语言：中文／EN／日本語／한국어／Español／Français。

## 谁决定什么

- 方向类决定（色彩方向、主要布局、关键影像入口、叙事方式）：设计稿经用户确认后才进生产。
- 文案、规格、售价、承诺、版权、下载材料：视觉任务不自动授权修改。
- 提交、推送、发布：只有用户明确同意才做。
