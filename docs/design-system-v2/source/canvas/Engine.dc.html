玻璃分层动效的交接稿：用手写 WebGL2 实现磨砂玻璃板与嵌入的银白块，三个主题对应三个场景。确认用此方案，Code 先前的 three.js 试点暂缓。

效果与交互
  • 左侧一摞 WebGL 玻璃板（SSD、底层 CUDA、中层 RMinte 推理层、顶层模型），右侧三条主题；点击主题切换场景，板子位置、缩放与内容平滑过渡。
  • 场景 1 沿用生态：顶层三条线、中层左侧小块加右侧整块；场景 2 更长上下文与并发：中层 KV 缓存格、前缀共享用蓝宝石，顶层三路流动，SSD 板出现；场景 3 整机设计：中层三个算子并拢加融合外框，顶层八层扫描。
  • 鼠标移动时相机轻微环绕（方位 ±0.22、俯仰 ∓0.1），光源随鼠标漂移；静止时板子缓慢浮动。
  • 标签是 DOM 元素，随各板最右顶点投影定位，不进画布。
渲染方案（决定：手写 WebGL2，不引入 three.js）
  • 不改依赖，不增加 Cloudflare 成本；原型即参考实现：design-preview/engine-glass/engine-webgl2.html，单文件约 360 行。
  • 每块板按“下到上”渲染：先画板内内容块与加性光晕，再把当前帧缓冲复制到带 mipmap 的纹理，最后画玻璃板：折射采样（9 点、色散）、磨砂层（textureLod 2.4 与 3.6）、菲涅尔反射程序化摄影棚环境、倒角边缘光、抖动。
  • 内容块是实例化的小圆角立方体，下沉约 0.045 倍板高嵌在玻璃里；实例缓冲每帧 bufferSubData 更新。
  • DPR 上限 2；IntersectionObserver 离屏暂停；WebGL2 不可用时显示文字提示，建议 Code 补一张静态图作后备。
