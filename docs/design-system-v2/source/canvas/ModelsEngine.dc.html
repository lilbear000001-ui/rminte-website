落地建议（重要）
  • 原型为复刻站点现有 CSS 的单文件页，仅用于表现。落地时在现有 .mp-engine-stack 上加类与子节点，保留 data-cells 由 JS 生成的做法，生成时给每个 i 设 --k。
  • Geist Pixel 站内已有；原型里用的是等宽字体兜底，请换为站内字体。2 MB 文案需补 zh/en 翻译键（en：Runner resident memory / Excludes weights, KV cache and context）。
  • 计数建议用 IntersectionObserver 进入视口时触发；离屏时暂停所有 infinite 动画（animation-play-state）。
  • CUDA 层 96 格的亮度动画改变 background，会触发重绘；建议改成叠一层白色 opacity 的方式，或减少参与格子数。
  • mobile 沿用现有 mp-engine 移动端规则；2 MB 在窄屏移到画面下方居中。
  • 减少动效：所有动画与光块关闭；C++ 仍保持合拢状态与静态「2 MB」。
  • 多语言长标签（ja/ko/es/fr 的 runtime 换行规则）要与新增标签位置一起检查。
