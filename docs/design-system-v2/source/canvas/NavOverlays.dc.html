导航、语言切换与联系弹层 · 优化稿

不用真玻璃：用统一的石墨材质、顶边随指针移动的光段和更清晰的状态，让导航与弹层更精致，并与整站语言一致。

效果与交互
  • 不做真玻璃。导航、语言、菜单按钮和弹窗用同一材质：石墨 n-3、1px 描边。顶边 1px 光段只用在两处较宽的元素上：导航岛和联系弹窗大框；语言按钮、菜单按钮、页脚「联系我们」按钮、语言下拉太短，不加。光段沿用站内已有的倒角边光（[data-bevel] + motion.js 的 --bx），随指针横向移动，惯性 0.14，静止时回到中间；触屏与减少动效时固定在中间。
  • 导航岛：背景由 n-3 85% 提到 92%（更稳、不受视频亮度影响），描边由 line-1 提到 line-2，与语言、菜单按钮统一；光段两端内缩 32px。首页的章节高亮改为白 10% 底加 1px 环（原为灰底）；子页的「当前页」仍是银白胶囊。
  • 语言切换：按钮高 42px（≤1120px 为 44px）；展开时箭头旋转 180°。菜单为 n-3 面板、1px line-3 描边、8px 圆角，去掉投影；每项 40px，选中项文字提亮并在右侧显示蓝宝石对勾（SVG，24 坐标、1.6 线宽），不再靠整块灰底；悬停 line-1 底。进场 240ms：透明度 + 上移 4px + 缩放 .98。
  • 联系弹窗：标题 28px；面板 n-3、line-3 描边、8px 圆角，顶边光段（保留）；打开时页面压暗（黑 55%，无模糊）并设为 inert，补 aria-modal；入口行用 line-2 细线分隔，邮箱 17px，悬停时蓝宝石下划线 480ms 从左画出、箭头向右上位移 2px；焦点环 2px 蓝宝石 + 4px 间距；关闭按钮 44px 圆形，焦点自动落在它上面，Esc 关闭并回到触发按钮。
  • 手机菜单：全屏，条目 32px，每行上下 1px 细线，左侧 Geist Mono 序号（当前页序号为蓝宝石）；顶部 Logo 与 44px 圆形关闭按钮。手机联系弹窗两侧留 16px、贴底。
  • 保持不变：文案、语言列表、链接、六语言、aria 标签、Esc/外部点击关闭等行为；主题色阶不新增颜色，全部取现有令牌。
