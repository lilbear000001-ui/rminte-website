落地建议（重要）
  • 在现有 svg.mp-glass-stack 里加一个 mask 和每层一个叠加组，不改按钮、aria-pressed、clipPath 与 viewBox。
  • 性能风险：每个堆叠 3 层、持续动画 + SVG mask + filter，真机 GPU 可能偏重。请 Code 用性能面板实测；若掉帧，先降级为：只保留 MoE 方块与一道扫光，或把亮度遮罩预烘成一张灰度图改用 CSS mask-image。
  • 离屏时暂停（IntersectionObserver）；页面不可见时暂停随机定时器。
  • 原型为了独立运行把图片内嵌了两份（约 3.7MB），落地时直接引用现有图片，不要内嵌。
  • 手机端沿用现有尺寸；方块明灭在窄屏可减少到 8 个。
  • 减少动效：关闭漂浮、扫光与明灭，保留静态图与展开交互。
