问题与对策

Findings
#问题证据对策优先级
01颜色令牌碎片化

styles.css 里约 40 种白 / 黑透明度（.035–.94）；#9a9da1、#b9bcbe 等灰写死在令牌之外；产品页与支持页的灰各自调。

建立 10 阶中性色 + 4 级文字 + 3 级线条，旧值一一映射，视觉几乎不变，后续任何调整只改一处。

P0
02首屏被「语言切换」卡住，且媒体过重

html.i18n-loading 令 body 在 333KB 的 translations.js 载入前保持 visibility:hidden；hero-bg.mp4 19.6MB、热管理 HD 视频 10.3MB、img4.png 7.5MB，另有多张 2–3MB 的 PNG。（体积为文件实测；实际加载策略待 Network 面板确认。）

当前语言文案随 HTML 直出，其余语言按需加载；视频保持原分辨率、只优化编码并海报先行；首页 PNG 转 WebP。目标：LCP < 2.0s（待实测）。

P0
03字号与行高无体系

仅标题有流体令牌；正文行高 1.9 偏松；规格参数写成一整句灰字，缺少数字层级。

九级字阶（含流体显示字号）；参数使用等宽数字（tabular-nums）+ 小号单位；中文正文行高收到 1.8。

P0
04硬件模块卡片层级弱

卡片大量空白，规格挤在底部 12px 灰字；两张卡内容长度不同导致底部不齐；没有视觉锚点。

卡内拆成「标题 / 一句话 / 规格网格」三层；规格大数字化；顶边加一条高光细线模拟倒角。见 05 号画板。

P1
05缺少标志性点缀色

全站纯中性。但产品自身有强辨识度的颜色：蓝宝石的冰蓝紫、热管理的冷暖光——界面没有呼应它们。

引入单一「蓝宝石信号色」，只用于焦点、选中、进度、关键数值单位，不做渐变与发光。已确认（D1）。

P1
06首屏层次平

指标行 12px 小字埋在视频底部；标题与副标题字号接近；缺入场编排。

RM-01 字标放大到 168px 作为视觉锚；指标行数字化；文字逐行遮罩入场。见 04 / 06 号画板。

P1
07动效只有一条缓动曲线

仅 --motion 一个令牌；没有时长阶梯、入场编排、悬停与焦点反馈的统一规则。

5 档时长 + 3 条缓动；入场「行遮罩上移」；数字计数；链接下划线展开；全部遵守 reduced-motion。

P1
08全屏点阵叠层

body::after 在整页叠 2.2% 不透明度、screen 混合的点阵 + 横线，肉眼几乎不可见，却多占一个全屏合成层。

要么删除，要么换成 3–4% 的静态颗粒（单张平铺图，无混合模式）。待确认（D4）。

决定记录

Decisions · 2026-10-03 更新
D1 · 点缀色已同意：蓝宝石信号色

只作细线、焦点、选中和数值单位；不渐变、不发光。图册页不使用。

D2 · 数据字体已同意：Geist Mono

仅用于参数数值与计数，单位用 sapphire-300。

D3 · 首屏版式已同意：RM-01 字标作视觉锚

保留视频与自动播放，只改文字层级与指标行。

D4 · 静态颗粒已同意：静态颗粒

给纯黑背景加一层几乎看不见的细噪点，让大面积黑更有质感、渐变不出现色带。只作用于首页与模型页，图册、下载、指南不加。

D5 · 媒体已同意，范围收窄如右

视频分辨率不变；PNG 转 WebP；编码优化只限首页；图册图片完全不动（保留最高清与 HDR）。

D6 · 支持页底色已同意：抬升黑 #0D0F12

指南与下载页原用借来的 #141618，不在色阶内。下载与指南两页统一改用 n-2，面板用 n-3。

D7 · 点阵数字字体已同意：Geist Pixel

与 Geist 同一家族，OFL 开源，只用于大数字与计数。图册显示照片真实 EXIF 也已同意。

原则图册图片是禁区

任何滤镜、叠层、压缩、尺寸变化都不应用到图册照片本身，叠层颗粒也不覆盖其上。

媒体策略（按 D5 修订）

Media policy
首页视频

分辨率不变（你试过降分辨率效果很差）。只在编码层面做功课：评估更高效的编码参数（同分辨率、同观感下降低码率）、关键帧间隔、faststart、海报先行、仅在进入视口时加载非首屏视频。每一版都要与原片并排比对，观感不如原片则放弃。

首页 PNG

转 WebP。仅限首页使用的 PNG（img3 / img4、散热叶片与模块图、握卡海报等）；先确认每张的实际引用位置，不动被其他页面引用的文件。

图册 11 张照片

保持原文件、原分辨率、原 HDR 信息。可做的只有「不改文件」的加载优化：预取相邻一张、解码提示、缓存头。是否加载策略有问题，需实测后才下结论。

其他页面

模型页、下载页、指南页的图片与视频本轮不动；如要动，先单独列出请你确认。
