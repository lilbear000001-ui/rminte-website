子页面诊断与规则

四类子页面职责不同：图册要「安静」，模型要「有信息量」，下载要「找得到」，指南要「读得下去」。共用同一套令牌，各自只调整密度与节奏。

依据：gallery.css / models.css / downloads.css / guides.css 与各页 HTML。指南正文（四篇长文）本轮只列规则，尚未出落地稿。

页面现状观察优化不可动
图册

标题 36px、简介 14px、HDR 提示灰字；照片 contain 完整展示；44px 圆形箭头；切换为 260ms 透明度。整体已经很安静。

计数改 Geist Pixel 点阵数字「09 / 11」（D7），并显示照片真实 EXIF；箭头与按钮加倒角高光；切换改 480ms 缓动；预取相邻一张（不改文件）；HDR 提示做成细边胶囊，图标保持银白。焦点环保持银白，不用蓝宝石色。

11 张照片原文件、顺序、contain、HDR；不加任何颗粒或叠层；不加缩略图条与分段进度（已确认移除）。

模型

卡片用 135° 线性渐变（#191d20 → #101214）与 8px 圆角；标签 11px 灰字；Dense / MoE 玻璃示意带 screen 混合；评测尚未公布。

卡片改平面 n-2 + 倒角高光 + 16px 圆角；架构标签（Dense / MoE）做成胶囊；模型名用 Quantify 放大；能力列表用细线分隔；可加 3–4% 颗粒（D4）。

Dense / MoE 动态示意、场景切换、粒子交互、引擎页签；评测预告与禁用的模型主页入口不伪造。

下载

行式列表是对的；文件类型块 56×64；元信息是一整句灰字「硬件安全与配套管理能力 · 中文 · 11 页 · PDF · 350 KB · 2026-09-11」，不好扫读。

元信息拆成字段：语言 / 页数 / 格式 / 大小 / 日期，用等宽小号；分类概览加当前章节的蓝宝石细线；行悬停 n-2 底；下载按钮仍是 44px 银白胶囊。

链接、文件名、版本日期、发布入口；不新增序号与英文装饰标签。

指南入口

搜索框（32px 圆角容器）很好；角色卡 admin / root / 安全 + 网络专题横卡；卡片 8px 圆角，悬停变灰；root 的「高权限操作」只是灰字。

卡片 16px + 倒角高光；章节数用等宽；root 卡的高权限提示加琥珀小点（功能语义色，不靠颜色单独表达）；搜索结果里命中词用蓝宝石下划线。

角色等权、搜索行为、目录锚点、复制、六语言。

指南正文

正文 16px / 行高 1.9；无外层大卡片；目录与锚点已有。

行高收到 1.85；目录当前章节加蓝宝石细线；代码块用 Geist Mono，复制按钮 44px；表头与代码块在自身容器内横向滚动（保持）。

内容层级、六语言正文、表格与代码的容器内滚动。
