指南 / 下载的底色，该是什么

同一段真实指南文字，放在三种底色上。左：现在使用的 #141618（借自其他页面）；中：纳入新色阶的「抬升黑」#0D0F12；右：产品页的纯黑 #000。

现状 · #141618文字 #B6BCC4 · 对比度 9.5 : 1 · 不在色阶内

进入 WebUI

首次使用默认密码登录时，页面会显示“安全提醒”。可以在弹窗中输入当前密码和新密码，随后点击“立即修改”。新密码需要输入两次并保持一致。

用户名保持为 admin，输入设备提供的 admin 密码。登录成功后，右上角会显示当前用户名。

推荐 · #0D0F12（n-2）文字 #B6BCC4 · 对比度 10.0 : 1 · 色阶内

产品页 · #000（n-0）文字 #B6BCC4 · 对比度 11.0 : 1 · 色阶内

进入 WebUI

首次使用默认密码登录时，页面会显示“安全提醒”。可以在弹窗中输入当前密码和新密码，随后点击“立即修改”。新密码需要输入两次并保持一致。

用户名保持为 admin，输入设备提供的 admin 密码。登录成功后，右上角会显示当前用户名。

现状。阅读不吃力，但这个灰是「另一个页面的颜色」，不属于品牌色阶；从纯黑的产品页切换过来，是一次突兀的换色，像换了一个网站。

推荐。仍比纯黑略抬升，缓解长文阅读时亮字在纯黑上的「发光感」，但与产品页同一色相，交接是自然的过渡。让页面不枯燥，靠的是结构（目录、步骤、提示块），而不是换底色。

纯黑。与产品页完全统一，最「高级」，但 16px 的中文细笔画在纯黑上更容易刺眼。如果你更想要统一，可以选它，正文色保持 #B6BCC4，不用纯白。
