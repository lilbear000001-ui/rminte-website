TianshanOS admin 日常使用指南

本指南面向使用 admin 账户管理 TianshanOS 的用户，介绍 WebUI 中的日常查看和操作功能。

9 个章节六种语言阅读约 25 分钟
开始使用 进入 WebUI 切换语言 页面导航 系统状态与常用操作 网络与文件 OTA 更新

开始使用

进入 WebUI

1

在浏览器中打开管理员提供的设备网页地址（WebUI）。

2

点击页面右上角的“登录”。

3

用户名保持为 admin，输入设备提供的 admin 密码。

4

点击“登录”。登录成功后，右上角会显示当前用户名。

首次使用默认密码登录时，页面会显示“安全提醒”。可以在弹窗中输入当前密码和新密码，随后点击“立即修改”。

使用完毕后，点击右上角的“退出登录”。再次操作设备时需要重新登录。

页面导航

admin 日常使用的主要入口如下：

  • “系统”：查看设备状态，控制模组、风扇和 LED，并进入 OTA 升级。
  • “网络”：查看以太网和 DHCP 状态，设置 WiFi 和 NAT 网络转发。
  • “文件”：管理 SD 卡和 SPIFFS 中的文件。
