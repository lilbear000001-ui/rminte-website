模型页 · 场景卡片光段分级（D9）

九张并列的场景卡片采用分级亮度的顶边光段：平时很淡，悬停与展开时升亮，让风格与首页统一又不吵。

决定
  • 采用 B 分级。规则：所有可点击卡片都带顶边光段，用亮度区分层级——主角 0.5 常亮；成排并列入口平时 0.18、悬停与键盘焦点升到 0.5 并随指针移动、展开项保持 0.5；不可点击的内容块无光。
  • 适用范围：只改模型页「驱动专业 Agent」下的九张场景卡片（.mp-case-card）。首页模块卡片、指南入口卡片、两张模型卡片保持常亮 0.5，不动。
  • 触屏与减少动效：固定在中间，亮度取平时值（0.18）；展开项仍为 0.5。
