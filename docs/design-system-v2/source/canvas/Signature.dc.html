标志性设计语言

不借用行业模板，只从产品本身取材：蓝宝石窗口的三角、前面板的 LED 点阵、机身倒角上的一线反光、散热的冷暖气流。五个手法，贯穿所有页面，互相呼应。

带「D6 / D7」的项目需要你确认：D6 = 采用 Geist Pixel（OFL 开源，与 Geist 同一家族）；D7 = 图册显示照片真实 EXIF。

01 · 棱镜 Prism

蓝宝石窗口，变成一枚符号

热管理
章节标记取代现在的短横线，章节名左侧一枚 12px 空心棱镜。光标悬停影像时，光标变成棱镜 + 「查看」。转场页面切换用三角形光圈展开（480ms，reveal 缓动）。边界只描边与 12% 填充，不发光；每屏最多出现一次大尺寸。
02 · LED 点阵数字 D6

数字像前面板那样亮起

140W

用在哪首屏指标、规格大数字、图册计数。进入视口时从 0 逐位点亮，1.2s。为什么RM-01 前面板本身就是圆点 LED 矩阵；这套字体与 Geist 同家族，授权为 OFL。边界只用于数字与单位，不用于标题和正文；小于 28px 改回 Geist Mono，保证清晰。
03 · 倒角边缘光

一线反光，跟着指针走

推理模块
应用模块
用在哪所有卡片、按钮、搜索框。指针经过时，顶边的高光段跟随指针横向移动。为什么像灯光扫过阳极氧化铝的倒角——这是金属的反应，不是发光特效。边界只有 1px 线，无模糊、无阴影；触屏与减少动效时固定在中间。

05 · 冷暖线 Thermal line

全站唯一允许的渐变：热量

用在哪热管理章节的温度示意、模型评测发布后的曲线、功耗条。暖色 #E58B5A 代表热，蓝宝石 #6E86E0 代表被带走的热。为什么来自散热视频里真实的气流颜色，是产品自带的色彩语言。边界只在数据线与细条上出现，宽度 ≤ 2px；不做背景渐变，不做按钮渐变。（示意曲线，非实测数据。）
