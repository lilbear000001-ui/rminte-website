首页 · 让整机协同有序（TianshanOS）

在现有平面模块图上做精修：线有生命、操作有先后、鼠标有一点空间感。这是视觉与动效参考，不替换现有 DOM 结构。

效果与交互
  • 保留现网的平面正视、磨砂渐变模块与细三线，不引入 3D、不加封装引脚（DESIGN.md 已明确）。
  • 新增：①每条线常驻一道缓慢流光，未点亮时很淡，点亮后变蓝宝石色并加快；线两端有小焊盘。②南北向设备控制时，数据包沿三条网络线从交换机流向两个 MAC/PHY 与 W5500。③OTA 依序 ESP32、W5500、RTL8367RB 点亮，旁带 1、2、3 序号圆圈，数据包逐段传递，循环 5.4 秒。④鼠标移动时三层错位视差。
  • 点亮规则与现网一致：功能聚焦的模块清晰（模糊 2.5px→0，450ms），其余保持磨砂。

落地建议（重要）
  • 原型是纯 SVG，只用来表现视觉与动效；现网是 HTML 按钮加 SVG 连线（assets/home-architecture.js，data-part、data-lit、aria-pressed），可点击、可聚焦、有无障碍名称。请保留现有 DOM 与交互，在其上叠加流光、数据包、序号与视差，不要用原型替换结构。
  • 数据包沿现有 routes 折线运动：用 path.getPointAtLength 取点，rAF 驱动；离屏暂停，reduced-motion 关闭。
  • 视差：给连线层、模块层、文字层三个容器设置不同的 transform，注意不要影响现有百分比定位的 HTML 模块（它们与 SVG 共用容器，需同步位移）。
  • 手机端的模块重排沿用现有 mobile 布局；序号圆圈位置需要重新放（桌面放在芯片外侧右上角，ESP32 放右下角）。
  • 多语言：原型是中文草稿；标签沿用现有翻译键。
