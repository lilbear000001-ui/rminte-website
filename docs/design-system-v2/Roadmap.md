## 阶段 0 实施记录（2026-10-03，用户已确认）

- **令牌**：v2 色阶（`--n-*`、`--text-*`、`--line-*`、蓝宝石、冷暖、琥珀）与迁移期的 `--lg-*` 桥接令牌在 `assets/styles.css` 开头。桥接令牌逐一承载旧值，替换字面量后计算样式与截图不变；组件迁到色阶时逐个删除。放在 `styles.css` 而不是 `brand.css`，因为 OTA 构建会内嵌 `brand.css`（`scripts/build-service-brand.mjs`），按「OTA 不动」保持原样；用户 2026-10-03 确认保持这样，OTA 页面以后单独设计。影像遮罩、蒙版渐变、照片文字阴影、推理／整机示意图配色是调好的参数，保留字面量；从未被任何页面命中的 15 条旧规则（`.craft-specs`、`.secondary-link` 等）未动，留待清理。
- **点阵叠层**：`body::after` 在 `styles.css` 后文已被 `display:none` 关闭，实测所有页面都没有渲染，也没有全屏合成层；已删除这三处死规则（含从未出现在 DOM 里的 `.ambient-field`）。颗粒按 D4 在阶段 3 加到首页与模型页。
- **语言包**：`translations.js`（333KB）拆为 `assets/translations/{ja,ko,es,fr}.js`；中文、英文不再加载语言包，其余语言只加载自己的一份；运行时切换语言时再按需加载。页头片段用 `document.write` 在解析期按语言引入对应文件，保持原有的脚本执行顺序。把首屏导航、指标行、语言按钮预渲染进 HTML、使首屏在脚本之前就绪：用户 2026-10-03 同意暂不做，阶段 1 重做首屏结构后再评估。
- **图片**：首页实际使用的两张 PNG——`thermal-fan-blade.png`（1.98MB → 1.23MB）与 `craft-card-slot-detail.png`（1.49MB → 1.10MB）——转成了无损 WebP，逐像素一致，PNG 原文件保留在仓库里。后者带 OpenAI 签发的 C2PA 内容凭证（AI 生成标识），WebP 不带这份凭证；用户已确认可以丢失。`img4.png` 仅作 `og:image` 被首页、下载、指南引用，不是首页独有，未动；`img3.png`、`rm01-card-hand-ad-v3/v4.png`、`thermal-cooling-module-v2.png` 没有任何页面引用，未动（后三者同样带 C2PA 凭证）。
- **视频**：用户在比对页确认后，`hero-bg.mp4` 换成 H.264 CRF 20 并去掉用不上的音轨（19.66 → 17.62 MB），`thermal-airflow-loop-hd.mp4` 由无损编码换成 H.264 CRF 10（10.35 → 2.14 MB）；分辨率、帧率、色彩标记不变，页面里的 `?v=` 已更新。`cartridge-tvc-v2.mp4` 不动。重新编码后这两处与原版不再逐像素一致：首屏第一帧平均差 0.4 级（最大 8 级／255），热管理章节平均差 2.1 级（最大 9 级）。原文件在 git 历史里。
- **动效原型**：点阵数字、倒角边光、棱镜光圈转场的独立原型在 `design-preview/motion-v2/`，未进入生产。
